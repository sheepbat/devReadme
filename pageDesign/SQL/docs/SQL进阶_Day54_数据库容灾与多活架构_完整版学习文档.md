# 三、容灾核心指标


# RPO


Recovery Point Objective。


恢复点目标。


表示：

最多允许丢失多少数据。


例如：

RPO=5分钟。


说明：

最多丢失5分钟数据。


---

# RTO


Recovery Time Objective。


恢复时间目标。


表示：

多久恢复业务。


例如：

RTO=10分钟。

最低级。


适合：

普通业务。


---

## 同城灾备


不同机房。

---

## 异地灾备


不同城市。


防止：

区域灾害。

# 五、主备架构


架构：


```
Primary

↓

Standby
```


特点：

简单。


缺点：

备用资源利用率低。


---

# 六、双活架构


两个节点：

同时提供服务。


```
Region A

↓

Region B
```


优势：

资源利用率高。


---

# 七、多活架构


多个区域：

同时工作。


例如：


```
北京

上海

广州
```


用户访问：

最近区域。
