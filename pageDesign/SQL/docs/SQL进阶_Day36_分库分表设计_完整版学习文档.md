- 索引巨大
- 写入压力高
- 维护困难

# 四、分库分表分类


主要两类：


## 垂直拆分


按照业务拆。


例如：


```
用户库

订单库

商品库

支付库
```


---

## 水平拆分


按照数据拆。


例如：


订单表：

```
order_0

order_1

order_2
```


---

# 五、垂直分库


原来：


```
一个数据库

用户

订单

商品

支付
```


拆分：


```
user_db

order_db

product_db

payment_db
```


优势：

降低业务耦合。


---

# 六、水平分表


例如订单：


原表：

```
orders
```


拆：

```
orders_0

orders_1

orders_2

orders_3
```
