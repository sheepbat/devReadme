# 三、为什么需要高可用


生产数据库风险：


## 1.服务器故障


例如：

硬件损坏。


## 2.MySQL异常


例如：

服务停止。


## 3.网络故障


无法连接数据库。


目标：

减少业务中断时间。


---

# 四、高可用核心指标


## 1.RTO


Recovery Time Objective。


恢复时间目标。


例如：

5分钟恢复。


---

## 2.RPO


Recovery Point Objective。


数据恢复目标。


例如：

最多丢失10秒数据。
