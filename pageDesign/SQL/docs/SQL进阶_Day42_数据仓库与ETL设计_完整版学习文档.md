# 二、为什么需要数据仓库


业务数据库：

主要服务交易。


例如：

订单创建。


特点：

高并发。


但是：

不适合复杂分析。


---

# 三、OLTP与OLAP


## OLTP


在线事务处理。


特点：

- 高频写入
- 单条查询
- 强事务


例如：

订单系统。


---

## OLAP


在线分析处理。


特点：

- 大量统计
- 聚合分析


例如：

销售报表。


---

# 四、数据仓库架构


典型结构：


```
业务数据库

↓

ETL

↓

数据仓库

↓

数据分析

↓

报表
```


---

# 五、数据仓库分层


经典四层：


```
ODS

↓

DWD

↓

DWS

↓

ADS
```


---

# 六、ODS层


Operational Data Store。


保存：

原始业务数据。


特点：

接近业务库。


例如：

订单原始表。


---

# 七、DWD层


Data Warehouse Detail。


明细数据层。


作用：

清洗数据。


例如：

统一订单格式。


---

# 八、DWS层


Data Warehouse Summary。


汇总层。


例如：

每天销售额。


---

# 九、ADS层


Application Data Service。


应用数据层。


直接服务：

报表。


---

# 十、ETL流程


ETL：

Extract

Transform

Load。


流程：


```
抽取

↓

清洗

↓

转换

↓

加载
```

## 增量抽取

例如：
