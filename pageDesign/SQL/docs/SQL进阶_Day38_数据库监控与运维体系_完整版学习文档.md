# 四、数据库核心监控指标


# 1.QPS


Queries Per Second。


每秒查询数量。


关注：

读取压力。


---

# 2.TPS


Transactions Per Second。


每秒事务数量。


关注：

写入能力。


---

# 3.连接数


查看：


```sql
SHOW STATUS LIKE 'Threads_connected';
```


问题：

连接过多。


---

# 4.慢SQL数量


关注：

执行时间。


---

# 五、慢SQL监控


开启：


```sql
SET GLOBAL slow_query_log=ON;
```


查看：


```sql
SHOW VARIABLES LIKE 'slow_query%';
```


分析：

- 执行时间
- 扫描行数
- SQL频率
