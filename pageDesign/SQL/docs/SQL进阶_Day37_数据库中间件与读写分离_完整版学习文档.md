# 六、读写分离问题


# 主从延迟


流程：


```
写入Master

↓

同步Slave

↓

读取Slave
```


可能：

读取不到最新数据。


---

# 七、解决主从延迟


方案1：

强制读主库。


例如：

订单创建后查询。


---

方案2：

延迟读取。


等待同步。


---

方案3：

根据业务判断。


重要数据：

主库。


普通查询：

从库。
