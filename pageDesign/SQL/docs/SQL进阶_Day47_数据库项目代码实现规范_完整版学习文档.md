# 三、表设计规范


## 1.表名规范


推荐：

小写下划线。


例如：


```
user_order
```


避免：

```
UserOrder
```


---

## 2.主键规范


推荐：

BIGINT。


例如：


```sql
id BIGINT PRIMARY KEY
```


---

## 3.公共字段规范


企业常见：


```sql
create_time

update_time

create_user

update_user

is_deleted
```


---

# 四、字段设计规范


## 类型选择


金额：

```sql
DECIMAL
```


不要：

FLOAT。


---

时间：

```sql
DATETIME
```


---

状态：

```sql
TINYINT
```


---

# 五、SQL开发规范


## 禁止SELECT *


错误：


```sql
SELECT *

FROM user;
```


推荐：


```sql
SELECT

id,

username

FROM user;
```

# 六、查询规范


避免：

循环查询。


例如：

N+1问题。


优化：
